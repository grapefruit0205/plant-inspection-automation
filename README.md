# 현장 점검표 자동 집계·주간보고 시스템

화학공장 유틸리티동 설비 20대를 매일 점검하는 현장을 가정한 **점검 기록 자동화 시스템**입니다.
종이 점검표와 수기 엑셀 정리를 없애고, 이상 징후를 **발견 즉시** 담당자에게 알리는 것이 목표입니다.

> ⚠️ **데이터 고지** — 이 저장소의 모든 데이터(설비 태그, 점검자 이름, 측정값, 메일 주소)는 **합성 데이터**입니다.
> 특정 회사의 실제 자료·양식·설비 정보를 사용하지 않았습니다.

---

## 1. 한 줄 소개

스마트폰으로 점검값을 입력하면 → 기준 초과 항목을 자동 판정해 담당자에게 메일을 보내고 → 매주 월요일 주간 보고서 PDF를 자동 발송합니다.

## 2. 문제 상황

- 종이 점검표는 이상값이 있어도 **사무실에 올라와야** 알 수 있었습니다.
- 주간 보고서는 매주 담당자가 **손으로 옮겨 적는 데 2시간**이 걸렸고, 옮겨 적는 과정에서 숫자 오류가 생겼습니다.
- 점검 기준(예: 압력 7.0 bar)이 계절·설비 노후에 따라 바뀌는데, 그때마다 개발자를 부를 수 없었습니다.

## 3. 시스템 구조

```
[스마트폰 구글폼] ──제출──▶ [구글시트: 원본응답]
                                   │ (폼 제출 트리거)
                                   ▼
                          Apps Script: onFormSubmit
                             ├─ 기준값읽기()  ◀── [기준값 탭]  ← 사람이 수정
                             ├─ 이상치판정()
                             ├─ 이상이력기록() ──▶ [이상이력 탭]
                             ├─ 메일알림()     ──▶ 담당자 Gmail
                             └─ 일일집계갱신() ──▶ [일일집계 탭]

[매주 월요일 07:00 트리거] ──▶ weeklyReport()
                             ├─ 주간요약갱신() ──▶ [주간요약 탭]
                             ├─ 보고서 문서를 코드로 생성(구글독스)
                             ├─ PDF 변환 → 드라이브 저장
                             └─ 관리자 메일 첨부 + PDF링크 기록
```

## 5. 주요 기능

| 기능 | 설명 |
|---|---|
| 실시간 판정 | 폼 제출 즉시 9개 항목을 기준값과 비교 (`초과` / `미만` / `값일치` 3가지 유형) |
| 자동 색상 표시 | 조건부 서식으로 기준 초과 셀을 빨강/주황/노랑으로 구분 |
| 담당자 알림 | 심각도·담당 부서별로 묶어 1통 발송 (`mech@` / `ops@` / `safety@`) |
| 일일 집계 | 제출 건수, 점검 설비 수, 미점검 설비, 최다 이상 항목 |
| 주간 PDF | 요약 카드·TOP3·이상 상세표가 든 보고서를 코드로 생성해 PDF 저장·메일 첨부 (심각도별 색 구분, 20건 초과 시 요약) |
| 기준값 외부화 | 임계값을 **코드가 아니라 시트**에서 읽음 → 셀 수정만으로 변경 |

## 6. 기준값 관리 방식

`기준값` 탭의 `판정유형`은 3가지입니다.

| 유형 | 동작 | 예 |
|---|---|---|
| `초과` | 측정값 > 기준값 | 압축기 토출 압력 7.0 bar 초과 |
| `미만` | 측정값 < 기준값 | 탱크 액위 20% 미만 |
| `값일치` | 측정값이 `이상값목록`에 포함 | 펌프 진동 "주의,이상" |

`사용여부`를 `FALSE`로 두면 그 항목은 판정에서 빠집니다.
기준을 바꾼 뒤에는 `전체재판정()`을 실행하면 과거 데이터까지 다시 판정됩니다.

## 7. 내가 결정한 것 3가지

| 결정 | 이유 |
|---|---|
| 임계값을 코드가 아니라 `기준값` 탭에 둠 | 계절·설비 노후로 기준이 바뀌는데 매번 개발자를 부를 수 없음 |
| 항목별 심각도와 담당자를 분리(기계/운전/안전) | 실제 조직은 누설과 밸브 잠금의 담당 부서가 다름 |
| "주의"도 이상으로 잡되 노랑으로 구분 | 진동은 조기 징후를 잡는 게 목적 — 심각도만 낮춤 |

## 8. AI 활용 방식

- 시트 구조, 판정 유형, 심각도 분리, 기준값 외부화는 **직접 설계**했습니다.
- Apps Script 코드는 Claude와 대화하며 작성·디버깅했습니다(오류 메시지를 그대로 전달하는 방식).
- 대화 로그: `docs/prompt-log.md`

## 9. 한계와 다음 단계

- 미점검 설비 알림(현재는 집계만), 이상 이력 기반 예방정비 추천, 사진 첨부는 다음 단계입니다.
- 폼 문항 제목을 바꾸면 시트 헤더와 어긋나 판정이 동작하지 않습니다 → 문항 수정 시 `기준값` 탭의 `원본컬럼명`도 함께 수정해야 합니다.

## 10. 실행 방법

1. 구글폼(`유틸리티동 일일 설비 점검표`)을 만들고 응답을 스프레드시트에 연결 → 응답 탭 이름을 `원본응답`으로 변경
2. `기준값`·`설비목록`·`설정` 탭을 만들고 `docs/설치가이드.md`의 표를 붙여넣기
3. 시트 → 확장 프로그램 → Apps Script → `Code.js` 붙여넣기, `appsscript.json` 반영
4. `트리거설정()` 1회 실행
5. 테스트: `테스트_판정()` → 폼 제출 → `_dev_가상데이터생성(28)` → `전체재판정()`

자세한 절차: [`docs/설치가이드.md`](docs/설치가이드.md)
