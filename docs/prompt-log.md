# Claude 대화 로그 (AI 활용 기록)

이 파일은 "무엇을 AI에게 맡기고, 무엇을 내가 결정했는지"를 남기는 기록입니다.
면접에서 **"AI가 다 만든 것 아니냐"**는 질문에 대한 답이 여기에 있습니다.

## 내가 결정한 것

| 결정 | 근거 |
|---|---|
| 판정 유형을 `초과` / `미만` / `값일치` 3가지로 단순화 | 현장 점검값은 숫자 비교 아니면 정해진 값 중 하나라서 |
| 임계값을 코드가 아니라 `기준값` 탭에 둠 | 계절·설비 노후로 기준이 바뀌는데 매번 개발자를 부를 수 없음 |
| 심각도·담당자를 항목별로 분리(기계/운전/안전) | 실제 조직은 누설과 밸브 잠금의 담당 부서가 다름 |
| 진동 "주의"를 이상으로 잡되 노랑으로 구분 | 조기 징후를 잡는 게 목적이므로, 알리되 심각도는 낮춤 |
| 메일을 담당자별로 묶어 1통만 발송 | 하루 20대 점검 시 메일 폭탄 방지 |

## 프롬프트 기록

> 사용한 프롬프트를 아래에 날짜순으로 추가하세요. 오류를 고친 과정도 그대로 남기는 것이 좋습니다.

### 1일차 — 구조 고정

```
구글시트 탭이 원본응답, 기준값, 이상이력, 일일집계, 주간요약, 설정이고
헤더는 [붙여넣기]야. 이 구조를 기억하고 앞으로 코드는 전부 이 헤더 이름으로
접근하게 해줘. 하드코딩 열번호 금지.
```

*(이하 실제 대화 내용을 복사해서 채웁니다)*

## 오류 해결 기록

| 증상 | 원인 | 해결 |
|---|---|---|
| `TypeError: Cannot read properties of undefined (reading 'namedValues')` | 편집기에서 `onFormSubmit`을 직접 실행하면 `e`가 없음 | 반드시 폼 제출로 테스트하거나 `테스트_판정()` 사용 |
| `Exception: Specified permissions are not sufficient to call Session.getActiveUser. Required permissions: .../userinfo.email` | `appsscript.json` 매니페스트에 권한을 직접 나열했는데 `userinfo.email` 이 빠져 있었음 | 스코프 추가. 게다가 권한이 없어도 설치가 중단되지 않도록 `try/catch` 폴백을 넣어 실패 지점을 없앰 |
| 재실행 시 "응답 탭을 찾지 못했습니다" | 첫 실행에서 이미 `원본응답` 으로 이름이 바뀌어 있어, 남은 탭을 찾는 방식이 통하지 않음 | 이름으로 먼저 찾고, 이미 있는 판정 열은 중복 추가하지 않게 수정 |
