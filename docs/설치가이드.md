# 설치 가이드 — 구글에서 처음부터 세팅하기

> 소요: 약 2~3시간 (1일차 오전~오후)

## 0. 준비

- 구글 계정(포트폴리오 전용 계정 권장)
- 드라이브에 폴더 생성: `점검시스템_포트폴리오`

## 1. 구글폼 만들기

1. <https://forms.new> 접속 → 제목: `유틸리티동 일일 설비 점검표`
2. 아래 12개 문항을 순서대로 입력

| # | 문항 | 타입 | 필수 | 선택지 / 유효성 |
|---|---|---|---|---|
| 1 | 점검자 | 드롭다운 | ✔ | 김민수, 이서연, 박지훈, 최유진, 정도현 |
| 2 | 설비 | 드롭다운 | ✔ | AC-01~AC-05, PU-01~PU-08, TK-01~TK-04, BL-01~BL-03 (총 20개) |
| 3 | 압축기 토출 압력(bar) | 단답 | ✔ | 응답 확인 → 숫자, 0~15 |
| 4 | 오일 레벨 | 객관식 | ✔ | 정상 / 보충필요 |
| 5 | 펌프 진동·소음 | 객관식 | ✔ | 정상 / 주의 / 이상 |
| 6 | 베어링 온도(℃) | 단답 | ✔ | 응답 확인 → 숫자, 0~150 |
| 7 | 탱크 액위(%) | 단답 | ✔ | 응답 확인 → 숫자, 0~100 |
| 8 | 배관 누설 | 객관식 | ✔ | 없음 / 있음 |
| 9 | 밸브 잠금 상태 | 객관식 | ✔ | 정상 / 해제됨 |
| 10 | 안전 커버·방호 | 객관식 | ✔ | 정상 / 파손 |
| 11 | 윤활 급유 | 객관식 | ✔ | 완료 / 미실시 |
| 12 | 특이사항 | 장문 | ✗ | — |

3. **응답** 탭 → 스프레드시트 연결(새로 만들기)
4. 설정 → **이메일 주소 수집은 끔** (개인정보 최소화)
5. 시트에서 응답 탭 이름을 `원본응답`으로 변경

> ⚠️ **문항 제목을 나중에 바꾸면 시트 헤더도 바뀝니다.** 바꿀 경우 `기준값` 탭의 `원본컬럼명`도 같이 고쳐야 합니다.

## 2. 시트 탭 6개 만들기

| 탭 | 헤더(1행에 그대로 입력) |
|---|---|
| `기준값` | 항목명, 원본컬럼명, 판정유형, 기준값, 이상값목록, 심각도, 담당자이메일, 사용여부 |
| `설비목록` | 설비태그, 설비명, 구역, 담당자, 담당자이메일 |
| `일일집계` | 점검일, 제출건수, 점검설비수, 미점검설비수, 이상건수, 이상설비목록, 최다이상항목 |
| `이상이력` | 발생시각, 점검일, 설비, 점검자, 항목명, 측정값, 기준, 심각도, 알림발송, 조치상태, 조치내용 |
| `주간요약` | 주차, 시작일, 종료일, 총제출, 이상건수, 이상률(%), TOP3설비, TOP3항목, 미조치건수, PDF링크 |
| `설정` | 키, 값 |

## 5. 주간보고 템플릿 문서 만들기

1. 구글독스 새 문서 → 전체 폰트 **Noto Sans KR**
2. 본문에 아래 자리표시자 입력

```
주간 설비 점검 보고서

기간: {{기간}}
총 제출: {{총제출}}건
이상 건수: {{이상건수}}건 (이상률 {{이상률}}%)
TOP3 설비: {{TOP3설비}}
TOP3 항목: {{TOP3항목}}
미조치: {{미조치}}건

[이상 상세]
{{이상표}}

생성일시: {{생성일시}}
```

3. 문서 URL에서 ID 복사 → `설정` 탭 `템플릿문서ID`에 입력
   (`docs.google.com/document/d/`**`여기`**`/edit`)
4. 드라이브 폴더 URL에서 ID 복사 → `설정` 탭 `PDF폴더ID`에 입력

## 6. Apps Script 붙여넣기

1. 시트 → **확장 프로그램 → Apps Script**
2. 기본 `Code.gs` 내용을 지우고 `Code.js` 전체를 붙여넣기
3. 왼쪽 **프로젝트 설정** → "appsscript.json 매니페스트 표시" 체크 → `appsscript.json` 내용으로 교체
4. 저장(Ctrl+S)
5. 함수 선택에서 `트리거설정` 선택 → **실행** → 권한 허용
   (경고 화면: **고급 → 프로젝트로 이동(안전하지 않음) → 허용** — 본인 스크립트라 정상)

## 8. GitHub에 코드 올리기

### 방법 A — 수동 (가장 빠름, 10분)

1. GitHub에서 저장소 생성: `plant-inspection-automation`
2. 로컬 폴더에서 아래 실행

```bash
git init
```

```bash
git add .
```

```bash
git commit -m "현장 점검표 자동 집계·주간보고 시스템"
```

```bash
git branch -M main
```

```bash
git remote add origin https://github.com/<사용자명>/plant-inspection-automation.git
```

```bash
git push -u origin main
```

3. 이후 Apps Script를 수정하면 **편집기 내용 전체 복사 → `Code.js`에 붙여넣기 → commit** 으로 동기화

### 방법 B — clasp (자동 동기화, 선택)

Node.js가 설치돼 있어야 합니다.

```bash
npm install -g @google/clasp
```

```bash
clasp login
```

1. Apps Script 편집기 → 프로젝트 설정 → **스크립트 ID** 복사
2. `.clasp.json.example`을 `.clasp.json`으로 복사하고 `scriptId`에 붙여넣기
3. 아래로 내려받기/올리기

```bash
clasp pull
```

```bash
clasp push
```

> `.clasp.json`은 스크립트 ID를 담고 있으므로 `.gitignore`에 넣어 두었습니다.

## 9. 주의사항

- **회사 자료 사용 금지**: 실제 점검표 양식, 설비 태그, 도면, 인명, 사진을 쓰지 않습니다. 전부 합성 데이터입니다.
- 시트 공유는 **"링크가 있는 모든 사용자 → 뷰어"**만. 편집 권한 공개 금지.
- 무료 할당량: 메일 100통/일, 트리거 실행 90분/일. 담당자별 묶음 발송이라 실제로는 문제되지 않습니다.
- 시간대가 9시간 어긋나면: 시트 **파일 → 설정 → 시간대 (GMT+09:00) 서울**, 그리고 `appsscript.json`의 `timeZone` 확인.
